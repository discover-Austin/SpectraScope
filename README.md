# SpectraScope: Night Sessions

SpectraScope: Night Sessions is an atmospheric entertainment app that delivers immersive simulation sessions inspired by paranormal investigation aesthetics.

## Product positioning

- Serious, documentary-style presentation
- Immersive simulation experiences only
- No claims about paranormal activity

## First-launch experience

1. Atmospheric intro
2. Boundary disclosure
3. Permissions explanation
4. Acknowledgment checkpoint

Completion is stored locally and can be revisited.

## Permissions

- Camera: Used to render live visual environments during simulation sessions.
- Microphone: Used to drive reactive audio-visual effects during simulation sessions.

No audio or video is stored or transmitted.

## Monetization

- Paid app download
- Optional non-consumable in-app purchase: SpectraScope Pro
- SpectraScope Pro unlocks advanced filters, extended sessions, and custom intensity presets

## Build

```bash
npm install
npm run build
npx cap sync android
```
